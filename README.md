# ZeroCOI Project Page

Project page for **Learning to Generate Text-guided 3D Canine-Object Interactions via Video Diffusion Priors** (SIGGRAPH Asia 2026).

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Project structure

- `index.html` — page content and metadata
- `static/css/index.css` — page layout and styling
- `static/js/` — scroll reveal, carousels, and video switching
- `static/images/` — favicon and project figures
- `static/pdfs/` — paper and supplementary material
- `static/results/` — result videos and button icons
- `static/videos/teaser.mp4` — teaser video

The repository remains private during development. GitHub Pages should only be enabled when the site is ready to be publicly accessible.
